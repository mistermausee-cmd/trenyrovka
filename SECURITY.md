# Security policy

## Reporting

Не публикуйте сведения об уязвимости в открытом issue. Сообщите владельцу репозитория приватным способом.

## Deployment baseline

- Используйте домен и HTTPS для доступа через интернет.
- Ограничьте SSH в Azure NSG своим IP и регулярно обновляйте Ubuntu/Docker.
- Не публикуйте `/opt/trenyrovka/.env`, SQLite-базу или каталог backups.
- GitHub PAT установщику нужен только на время скачивания приватного репозитория; установщик удаляет переменную перед Docker build и не записывает её.
- Периодически копируйте зашифрованный backup вне VM и проверяйте процедуру восстановления.

## Secrets

Репозиторий не должен содержать `.env`, `*.db`, session cookies, GitHub tokens или экспортированные тренировочные данные. Эти пути исключены через `.gitignore` и `.dockerignore`.
